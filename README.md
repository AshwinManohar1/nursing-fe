# ShiftWise

A modern workforce scheduling and shift management application built with React and TypeScript.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **UI Library**: Material UI (MUI)

## Getting Started

### Prerequisites

- Node.js >= 18
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/    # Reusable UI components
├── pages/         # Route-level page components
├── hooks/         # Custom React hooks
├── types/         # TypeScript type definitions
└── utils/         # Utility functions
```
